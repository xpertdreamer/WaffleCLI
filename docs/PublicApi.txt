## Usage Guidelines

1. For application setup: Use TuiApplicationBuilder
2. For component creation: Use ComponentFactory
3. For layout: Use SimpleGridLayout or StackLayout
4. For configuration: Use BinariesManager and SettingsManager
5. For logging: Use TuiLogger (static class)

## Example Usage

var app = new TuiApplicationBuilder()
    .UseRootComponent<MyApp>()
    .Build();

var button = ComponentFactory.CreateButton("btn1", "Click me!")
    .WithPosition(10, 5)
    .WithSize(20, 3);

var grid = ComponentFactory.CreateGrid("mainGrid", 2, 2)
    .WithSize(100, 30)
    .AddToGrid(button, 0, 0);
